## Which language is this? {#language}

The fix is not "detect the language" — it is deciding what may be believed,
and what to do when nothing is known. A wrong language is worse than no
language, because a service told the wrong one answers anyway.

```oku-diagram
{"src":"flowchart TB\n    SUB[\"What is being translated\"] --> WORD{\"A dictionary definition?\"}\n    WORD -->|yes| EN[\"English, by construction\"]\n    WORD -->|no| DET{\"Browser has a detector?\"}\n    DET -->|yes| EVID[\"Detected — evidence\"]\n    DET -->|no| LANG{\"lang declared near the selection?\"}\n    LANG -->|yes| DECL[\"Declared — a claim, not a reading\"]\n    LANG -->|no| NONE[\"Unknown\"]\n    EN --> BOTH[\"On-device or online, either may be asked\"]\n    EVID --> BOTH\n    DECL --> BOTH\n    NONE --> AUTO[\"Only a service that detects for itself\"]\n    AUTO --> G[\"Google: sl=auto\"]\n    AUTO --> MM[\"MyMemory: skipped — langpair has no autodetecting form\"]","caption":"Four sources of an answer, ordered by how much each can be trusted, and one branch for having none. The on-device translator needs both languages named, so it is skipped rather than guessed at; online, a service that cannot detect is skipped rather than told something false."}
```

The nearest `lang` wins over the document's, because a quotation in another
language is both the case where the document's own declaration is wrong and
the case where knowing the language matters most.

Two smaller things fell out of the same change: `en-GB` to `en-US` no longer
spends a request to be handed the input back, and nothing is detected at all
when there is no translator and the online one is off — which is the default.

## What is new in the card {#new}

Site marks. Every "Look up in" chip and every source in the footer carries a
monogram in that site's colour, and the same site looks the same in both
places, so the footer says which of the links above answered rather than
listing lowercase names.

They are drawn rather than fetched. A real favicon means bundling other
people's logos or asking the browser for one per site — which costs a
permission, returns nothing for a site never visited, has no answer in
Firefox, and fails on any page whose policy blocks images. The letter also
means colour is never the only signal.

The part that earns its keep is not the styling. Links minted by a provider
carry labels that do not name their site, and a mark resolves from the link's
host when its id is not a site the table knows — which is how a chip called
`Homepage` ends up saying GitHub.
