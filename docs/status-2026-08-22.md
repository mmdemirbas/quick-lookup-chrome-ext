### The credit that named nothing {#credit}

Reading those terms properly turned up a second thing they ask for, which
the card was also not doing: *"Include a visible attribution to
FreeDictionaryAPI.com."*

A card's `sources` are provider ids — short, lower-case, chosen to be typed
rather than read — and the footer was printing them. So the credit said
`free-dictionary`, which is a string that names no site and cannot be looked
up. The credit was present, it would pass any review that checked whether a
credit exists, and it did not do the one thing the requirement is for.

Sources are now printed by name, in the card's foot and in every copy. The
copy matters more than the card: it leaves the extension, and it is what a
note read weeks later has instead of the page. The names are a hand-written
table rather than the providers' own labels, because neither the card nor the
export may import the provider graph — every provider's code would land in
the content script — and a test walks the real providers so the table cannot
drift away from them quietly.

Sites and parts of speech are told apart by shape rather than by hue, which
is what keeps two colour systems on one card from reading as one confused
system: a site is a filled two-letter tile, a part of speech is a lower-case
italic word.

## Colour you could not read {#contrast}

The palettes live in `core` as hue numbers. The lightness that turns a hue
into ink lives in the card's stylesheet. Neither file knows what the pair
looks like, and nothing in the repository was in a position to find out.

Two site marks were below the 4.5:1 that WCAG asks for at the monogram's
size. They had shipped that way. The part-of-speech palette was about to do
the same, at 4.24:1 for an adverb, and was caught before it shipped only
because the same arithmetic was run on it.


The bar is where each colour reads now, the tick behind it is where it read
before, and the shaded boundary is 4.5:1. Two marks were on the wrong side
of that line — free-dictionary at 4.36 and tatoeba at 4.45 — and two more
sat on it at 4.52, close enough that any new hue between them would have
gone under. The adverb, at 4.24, would have joined them had the same
arithmetic not been run on it before it shipped. All five now read between
4.70 and 5.03.

The fix is one number in each of two rules: the mark's letter goes from 30%
lightness to 28%, and the part of speech is written at 32%. Both were chosen
by the weakest hue in the palette rather than the average, because a palette
is only as readable as its palest member.

The guard matters more than the fix. `src/content/palette.test.ts` computes
the contrast the browser will produce, for every entry in both palettes, in
both colour schemes — and reads every number out of the stylesheet rather
than repeating it, so it cannot pass while the stylesheet says something
else. It was run against the old values first, and named both failures
rather than passing regardless.

## The panel {#panel}

The roadmap of 11 August specified a depth surface: a dossier behind the
card's "More" action, holding history, exports and anything long. Between
then and now, every one of those moved somewhere better.

```oku-table
{"headers":["What the panel was specified to hold","Where it actually lives now"],"rows":[["History and bookmarks","The toolbar popup, with starring — a starred word survives both the size cap and Clear"],["Export to clipboard, Markdown, Anki","A row at the foot of the card itself, where what you are exporting is in front of you"],["The meanings that would not fit","An expander in the card. `bank` shows six of nine and says so"],["Anything long","The card scrolls, capped against the room the window actually has"],["Two words on screen at once","Dragging a card detaches it, and the next selection opens beside it rather than on top"]]}
```

What none of that covers is that a card lives in a content script and dies
with its page. That is the whole of what was left, so it is the whole of
what was built: the same card, in a place the page cannot take away, plus
the list of recent words underneath so one can be reopened without finding
the page it was on.

It mirrors rather than competes. Whatever was looked up last, in whichever
tab, is what the panel shows. The only lookup it starts itself is the one
asked for from its list.

### Where it can be opened from, and why that was not a choice {#gesture}

Chrome documents `sidePanel.open()` as callable "in response to a user
action". That sentence does not say which contexts count, and the difference
decides the whole design — so it was run rather than assumed.

```oku-table
{"headers":["Called from","With a user action?","Result"],"rows":[["The service worker","No","Refused — `sidePanel.open()` may only be called in response to a user gesture"],["An extension page","No","Opened"],["A context-menu click","Yes, delivered to the worker","The pattern Chrome's own documentation uses"]]}
```

A button in the card therefore cannot open the panel. That press happens in a
page and reaches the extension as a message, which leaves the service worker
making the call with nothing behind it — the first row. So the two entry
points are the context menu and the toolbar popup, which is an extension
page. The browser suite runs that refusal rather than trusting the sentence,
so the day Chrome changes its mind the check will say so.

Firefox's `sidebarAction.open()` is documented as needing a user action too.
That half has not been run — there is no Firefox harness here — and the code
says so where it matters.

### What it cost the rest of the code {#reuse}

The card renders itself into the panel rather than being rewritten for it. A
docked card is mounted inside a given element and gives up what only makes
sense floating over a page: placement, dragging, pinning, and the two buttons
that act on the page underneath. Forty-five lines in the renderer, no second
copy to keep in step.

The recent-lookups list became one component drawn in both surfaces. Doing
that surfaced a real ordering defect: a card is finished before the lookup
that produced it is written down, so a panel that refetched its list when the
card arrived drew the list without the word it was showing. The background
now says when the history changed, after the write.
